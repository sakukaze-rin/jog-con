# Jog-con

使用 Nintendo Joy-Con 控制 Adobe Premiere Pro 时间线的 macOS 原生工具。

> 当前实现只筛选并测试过 **Joy-Con (L)**。Joy-Con (R)、左右 Joy-Con 组合、Pro Controller 和其他兼容手柄目前没有完成适配或实机验证，不能视为已支持。

SwiftUI 设置界面、GameController 输入、CoreMIDI 虚拟端口、Mackie Control 相对 Jog，以及方向键面板聚焦。用户已在 Premiere 完成连续 Jog 联调。

摇杆自动识别短推和长推，无需手动切换：

- 短推超过单步幅度（默认 45%），回中发送 K 暂停后发送一次上一帧/下一帧快捷键；没有辅助功能权限时回退 MIDI Jog。
- 长推超过 85% 并保持 300 ms：有声模式用 J/L 从正常速度开始，持续到底每 0.8 秒追加一次同向键，最多 4 档；速度档位显示的是本工具发送级别，实际倍率由 Premiere 决定。
- 有声关闭时长推走连续 MIDI Jog，幅度控制脉冲速度，需要 Premiere MIDI 端口绑定。短推不受有声开关影响。
- 回中停止，转向先停止并重新从第 1 档开始；切出 Premiere、断连、关闭输出和正常退出会停止工具启动的有声播放。
- 用户已确认键盘事件路径能够有声播放，MIDI Jog 无声。新版加速、单帧与映射界面仍需实机验收。

## 自定义按钮映射

点击「添加映射」→ 选择按钮或点击「学习」并按一下实体键 → 选择执行动作。学习时会关闭输出，完成后需重新启用。

- 「自定义快捷键」可录制 Command / Shift / Option / Control 与普通键、箭头等组合；Esc 取消。
- Premiere 预设含面板、播放/停止/快退快进、逐帧、标记/入点/出点、撤销/重做、添加编辑点。它们通过 Adobe 默认快捷键执行，不是直接调用 Premiere API；自定义过快捷键请录制自己的组合。
- MCU Play/Stop/Rewind/Fast Forward 通过 MIDI 控制面板协议发送，需端口绑定；实际宿主响应需验证。
- 旧版六项绑定自动迁移；映射自动保存，可删除。重复绑定同一实体按钮只执行第一条，并显示提示。

## 兼容性

当前控制器发现逻辑会主动匹配 `Joy-Con (L)`、`Joy-Con L` 和系统报告的左右组合名称，并使用 GameController 提供的方向键、摇杆轴和按钮。Joy-Con (R) 的按钮布局、系统名称和输入别名可能不同，因此目前不会被可靠地自动选中；即使 macOS 能识别它，也不代表 Jog-con 已经能正确控制。右手柄支持需要单独确认设备发现、轴映射、按钮映射和摇杆按压。

## 隐私

本项目没有网络请求、遥测、分析 SDK 或账号功能。它只在本机读取 GameController 输入，把快捷键事件发送给前台的 Premiere Pro，并创建本机虚拟 MIDI 端口。设置和按钮映射保存在 macOS 的应用偏好中，不会上传。仓库中不包含开发者用户名、绝对路径、个人文件、访问令牌或签名证书；`build/`、`.build/`、`.DS_Store` 等本机构建文件也已被 Git 忽略。
